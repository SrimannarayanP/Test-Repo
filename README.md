# events. - Student Event Management Platform

A modern, student-friendly event management platform designed specifically for college and school events. Built with the aesthetics of Flyhyer and the bold design philosophy of Comet sneakers.

## 🎯 Problem We Solve

Traditional event management for students is chaotic:
- **WhatsApp Hell**: Google Forms links lost in endless group chats
- **Confirmation Calls**: Organizing committees calling 200+ participants individually
- **Spreadsheet Chaos**: Data scattered across multiple sheets with duplicates
- **Frustrated Everyone**: Stressed organizers and confused participants

## ✨ Features

### For Students
- **Instant Registration**: Beautiful, mobile-first forms that actually work
- **Smart Check-ins**: QR codes and real-time attendance tracking
- **Social Integration**: Share events anywhere, track engagement everywhere
- **Zero Learning Curve**: If you can use Instagram, you can use events.

### For Organizers
- **Launch in Minutes**: From idea to live event in under 10 minutes
- **Real-time Analytics**: Know what's working, fix what's not
- **Actually Free**: Not "freemium" or "free trial" - just free for students
- **Never Shy, Never Sorry**: Bold tools for bold events
